# Контент-завод

## Название
Контент-завод

## Проблема
Написание постов для соцсетей отнимает время: нужно придумать текст, заголовок, призыв к действию и хэштеги — и всё это под конкретную аудиторию и нужный тон.

## Пользователь
Маркетологи, SMM-специалисты, малый бизнес, самозанятые — все, кто ведёт соцсети и хочет публиковать регулярно без лишних затрат времени.

## Основная функция
По 4 входным параметрам — тема, описание продукта, целевая аудитория, тон — сервис генерирует готовый пост через Claude API и публикует его в соцсети.

## Формат результата
Страница с готовым постом:
- заголовок
- текст
- CTA (призыв к действию)
- хэштеги

Кнопки: «Скопировать», «Опубликовать в Telegram», «Опубликовать ВКонтакте».

## Минимальный функционал (MVP)
- Форма ввода: тема, продукт, ЦА, тон
- Генерация поста через Claude API
- Отображение результата на странице
- Публикация в Telegram
- Публикация ВКонтакте
