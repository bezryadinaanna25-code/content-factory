# Контент-завод

## Название
Контент-завод — подготовка и публикация постов на четыре площадки.
Сделан для музыкального проекта «Повелитель струн».

## Проблема
Проект ведёт сразу несколько площадок, и один и тот же пост приходится раскладывать по ним
вручную: переписывать текст под формат каждой, отдельно готовить фото и видео, следить,
чтобы ничего не ушло дважды и ничего не потерялось. На регулярном графике это съедает
больше времени, чем написание самого текста.

## Пользователь
Небольшой проект без отдельного SMM-специалиста: артист, мастер, малый бизнес — те, кто
публикуется регулярно и ведёт несколько площадок одновременно.

## Основная функция
Пост готовится один раз и хранится файлом: текст под каждую площадку, ссылки на фото
и видео. Черновик пишет Claude по теме от владельца, человек читает и правит его до отправки.
Дальше скрипт сам раскладывает пост по площадкам и отчитывается, что куда ушло.

## Формат результата
Запуск одной командой: скрипт находит посты с сегодняшней датой и публикует их.
После публикации рядом с постом появляется архивный файл `...-published.json` — он же
не даёт отправить один и тот же пост повторно.

## Что реализовано
- **Хранение постов:** JSON-файл на пост — отдельный текст для каждой площадки, ссылки на медиа
- **Подготовка текста:** черновик генерирует Claude, публикация только после проверки человеком
- **Telegram:** публикация через Bot API
- **ВКонтакте:** публикация через VK API, посты и истории
- **MAX:** публикация через управление браузером (Playwright), у площадки нет открытого API
- **Rutube:** загрузка видео через управление браузером (Playwright)
- **Медиа:** фото и видео из папки проекта, с подготовкой под требования площадок
- **Защита от дублей:** архивный файл после каждой публикации
- **Подтверждения:** снимки экрана и логи каждого шага в папках `*-evidence/`

## Технологии
- Python (скрипт публикации, работа с API)
- Node.js + Playwright (площадки без API)
- Telegram Bot API, VK API
- Claude API — генерация черновиков
- Создано с помощью Claude Code
